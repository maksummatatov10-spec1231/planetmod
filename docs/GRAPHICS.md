# ЭТАП 4 — ГРАФИКА, СПРАЙТЫ, АНИМАЦИИ (ПЛАН)

## Стратегия

1. **Иконки (обязательно, качественно):** процедурная генерация скриптом `tools/gen_icons.py`
   (Python + Pillow): рисование вектороподобных иконок на прозрачном фоне — кристаллы, капли,
   молнии, колбы, силуэты построек. 64×64 (предметы/флюиды), 128×128 (технологии/ачивки),
   128/512 (планета: starmap 512 + icon 128).
2. **Спрайты построек:** V1 — procedurally generated simple silhouettes (2–4 кадра анимации
   работы: вспышки/вращение) или **tinted-копии ванильных** (проверить поддержку tint; fallback —
   чистые ванильные спрайты). Кастомные полноценные спрайты — этап полировки.
3. **Тайлы:** переиспользование ванильных тайлов (типа `dry-dirt`, `sand-*`, `volcanic-ash-*`)
   + `terrain_tint_effect` для идентичности; кастомные тайлы — полировка.
4. **Декорации/деревья:** свои `simple-entity` (скалы-кристаллы, вентили, обломки) с tinted
   pictures; деревья — кастомные `tree` с tint (если поддерживается) или ванильные засушенные
   деревья как fallback.
5. **Анимации:** молния (свой `lightning` прототип с graphics_set — проверка на бинарнике;
   fallback — ванильная), smoke-эффекты вентилей (create-trivial-smoke из planet player_effects),
   мигание сифона (sprites с кадрами), вспышки в момент удара (lightning_warning_icon).

- Грунт: `#3a2b52` → `#241a38` (фиолетовые базальты), разряды `#d8ff3a`/`#9effff`,
- Озёра конденсата: `#1e6f6b` → `#0f3f3c`,

## Требования к иконкам

- Прозрачный фон; читаемость на 32px в инвентаре; без мелких деталей < 3px;
- Стиль ванили: тёмная обводка, один источник света сверху; тест — уменьшение до 16px.
