Примечания к шагам 11–13:
- 11: молния (60 урона / 600 МДж, фиолетовая), частота 1/(60·6) на чанк выше Фулгоры,
  приоритеты целей (сифон 10000, генератор 2000, жерло 90, трубы/столбы 10, роботы 100, руды 1),
  период супершторма по умолчанию 30 мин, зарядка конденсата 30 при 300 °C, буфер машин 500 МДж,
  пересчёт стоимостей машин.
- 12: данные без патчей чужих модов (только аддитивное изменение lab.inputs), опциональная
  PlanetsLib-интеграция за guard'ом (data-updates.lua), анализ в docs/DEPENDENCIES.md.
- 13: fallback-ветки (нет молнии → explosion; нет суперштормов → движковые молнии; pcall на
  статистике/спавне; миграция storage) реализованы и проверены статически; живой прогон
  (control.lua, event-имена, статистика) входит в шаг 14.

Принцип: каждый шаг = спроектировать → сверить с документацией → реализовать → проверить →
исправить → записать fallback → только потом следующий шаг. Никогда не оставлять сломанную
систему ради красивой идеи.
