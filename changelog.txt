Version: 0.1.2
Date: 2026-08-30
  Changes:
    - Fixed load crash on Factorio 2.x: build-entity-achievement uses the
      `to_build` field (the pre-2.0 `entity` field is gone; "Siphon network"
      achievement now uses `to_build = "storm-siphon"`).
    - "Mined dry" achievement reworked: DepleteResourceAchievementPrototype in
      2.x has no `resource` field (only amount), so the stormite-patch
      achievement is now unlocked by script via on_resource_depleted when a
      stormite-ore patch is depleted (semantics preserved).
    - tools/check_lua.py: new AST check validates every achievement prototype
      (required fields per type, rejects legacy `entity`/`resource` fields;
      verified against deliberately broken copies).
    - Release archive rebuilt as cataclysm_0.1.2.zip (the 0.1.1 archive did
      not load and was removed).

---------------------------------------------------------------------------------------------------
Version: 0.1.1
Date: 2026-08-30
  Changes:
    - Fixed load crash on Factorio 2.x: recipes used the pre-2.0 `category`
      field; replaced with `categories = { ... }` (RecipePrototype merged
      category + additional_categories into the categories table).
    - Hardened vanilla-changes.lua: removed the `table.find` call (not used by
      vanilla data in 2.x) in favour of a plain loop.
    - tools/check_lua.py: new AST check enforces `categories` on every recipe
      and rejects the legacy `category` field (verified against a deliberately
      broken copy).
    - Release archive rebuilt as cataclysm_0.1.1.zip (the 0.1.0 archive did
      not load and was removed).

---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 2026-08-30
  Changes:
    - Full playable planet "Cataclysm" beyond Aquilo (space connection aquilo-cataclysm).
    - Map generation: Aquilo-style noise (islands, starting ore spots, storm condensate lakes).
    - Natural risk: constant lightning (Fulgora-style) + scripted superstorm cycles (period setting).
    - Resources: stormite ore, astrite ore (deep/rare); fluids: storm condensate, charged condensate.
    - Machines: condensate extractor, storm siphon, storm foundry, storm fabricator, storm generator.
    - Production loop: condensate -> charging (lightning) -> charged condensate -> power + science.
    - New science pack: cataclysmic science pack (added to labs with cryogenic input).
    - 12 technologies, 11 achievements (7 native + 4 scripted).
    - Decoratives: crystal trees, cracked rocks, storm vents, ancient spires (spire reward).
    - Localization: en, ru, de (all entities/recipes/techs/achievements/messages).
    - Procedural graphics (PIL) for all icons, tech/achievement icons, ore sheets, decoratives.
    - Static checks: tools/check_lua.py (syntax, graphics refs, locale parity, recipe unlock),
      tools/check_icons.py (PNG integrity/sizes).
    - Additive vanilla change only: cataclysmic science pack added to lab inputs.
    - Optional PlanetsLib integration (data-updates): orbit-tree registration
      (planet moves with Aquilo), borrowed Aquilo music, default import location.
    - Dependency study documented in docs/DEPENDENCIES.md (PlanetsLib, flib, stdlib).
    - Release packaging: tools/make_release.py -> release/cataclysm_0.1.0.zip.
    - Custom lightning type (deepcopy of the Space Age lightning, purple tint,
      60 electric damage, 600 MJ strike energy) used by the planet and the superstorm.
    - Balance pass per docs/DESIGN.md: storm frequency 1/(60*6) per chunk
      (above Fulgora), machine strike priorities (siphon 10000, storm generator 2000,
      vent 90, poles/pipes/pumps 10, robots 100, ores 1); superstorm period
      default lowered to 30 minutes; charged condensate output 30 at 300 C;
      storm machines buffer 500 MJ; machine recipes re-costed.
    - Scripted achievements moved to production-statistics polling
      (LuaFlowStatistics.output_counts; Factorio 2.x has no recipe-finished event):
      eye-of-the-storm = lattice crafted during a superstorm,
      overcharged = 10 000 charged condensate produced.
    - Sound stage: named superstorm sounds (distant thunder + lightning cracks
      via SoundPrototype, referenced from the game's own audio), scripted
      positional thunder around players during superstorms and storm start/end
      cues; custom walking/driving sounds for the Cataclysm ground tiles
      (Space Age rock footsteps). All machines keep the battle-tested working
      sounds inherited from their vanilla source entities.
    - Fixed load crash: the storm generator now copies the steam-turbine
      prototype (data.raw.generator.turbine does not exist in Factorio 2.x).
    - Fixed load crash: recipes used the pre-2.0 `category` field; replaced
      with `categories = { ... }` (RecipePrototype in 2.x merged category and
      additional_categories into the categories table). tools/check_lua.py now
      enforces this (AST check, verified against a deliberately broken copy).
    - Hardened vanilla-changes.lua: removed the `table.find` call (not used by
      any vanilla data in 2.x) in favour of a plain loop.
    - HD graphics stage: all item/fluid icons regenerated natively at 128x128
      (icon_size 128, transparent, grid-friendly margins); decorative sprites
      redrawn at 256x256 and rendered at scale 0.5 (2 tiles tall,
      bottom-anchored to the tile grid); the storm vent (4 frames) and the
      crystal tree (3 frames) are now animated (2x2 frame grids with random
      animation offset), ore sheets stay 8x8 of 128px.
