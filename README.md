# Cataclysm — planet mod for Factorio Space Age

**Катаклизм** — поздняя грозовая планета для Factorio 2.1 (Space Age), доступная после Aquilo.

- Собственная планета с уникальным природным риском (молнии + суперштормы)
- Новая руда (штормит), редкий катализатор (астрит), электролитная петля заряда
- Новые постройки: экстрактор конденсата, штормовой сифон, штормовая кузня, фабрикатор, генератор
- Новый science pack: катаклизмический
- ~12 технологий, 11 достижений, локализация на 3 языках (en/ru/de)
- Процедурно генерируемые иконки; fallback-реализации для каждой рискованной системы

Требования: Factorio 2.1.x + Space Age. Совместимость: не меняет ванильные рецепты (добавление
в готовое сохранение безопасно); протестировано на 2.1.17.

Документация: `docs/RESEARCH.md` (исследование), `docs/DESIGN.md` (дизайн), `docs/ARCHITECTURE.md`,
`docs/GRAPHICS.md`, `docs/TESTING.md`, `docs/ROADMAP.md`.
