# Cataclysm — planet mod for Factorio Space Age

**Катаклизм** — поздняя грозовая планета для Factorio 2.1 (Space Age), доступная после Aquilo.
Планета задумана как «Фулгора наоборот»: у Фулгоры молнии — постоянный ночной фон, у Катаклизма
постоянная гроза усиливается редкими разрушительными **суперштормами**, а местная экономика
построена на превращении энергии молний в **заряженный конденсат** — топливо и электролит.

## Содержание

- Собственная планета (за Aquilo, соединение `aquilo-cataclysm`), уникальный мапген в стиле Aquilo:
  острова, озёра грозового конденсата, кристальные леса, разломы, редкие древние шпили.
- Уникальный природный риск: постоянные молнии (lightning_properties, как у Фулгоры) +
  скриптовые суперштормы (период настраивается, в центре — удары вокруг игрока).
- Ресурсы: `stormite-ore` (штормит), `astrite-ore` (астрит — редкий, глубокий).
- Электролитная петля: конденсат → зарядка молниями → генератор; две жидкости.
- Новые постройки: `condensate-extractor`, `storm-siphon` (громоотвод-накопитель),
  `storm-foundry` (плавка/зарядка), `storm-fabricator` (сборка), `storm-generator`.
- Новый science pack: `cataclysmic-science-pack` — вставляется во все лабы с cryogenic входом.
- 12 технологий (от «Добычи конденсата» до «Повелителя шторма»), 11 достижений
  (7 нативных + 4 скриптовых), локализация на 3 языках (en/ru/de).
- Процедурно генерируемые иконки/спрайты (PIL, `tools/gen_icons.py`), единая палитра.
- Запасной путь (fallback): все рискованные системы имеют упрощённую версию — см. docs/DESIGN.md.

## Установка

1. Factorio 2.1.x с дополнением Space Age.
2. Скопировать папку `planetmod` в `mods/` (или собрать zip и положить в `mods/`).
3. Запустить игру. Планета появляется на карте звёздной системы за Aquilo.

## Совместимость и сохранения

- Мод **аддитивен**: не переопределяет ванильные прототипы, только добавляет свои
  (единственное изменение ванили — добавление science pack во входы лабов в `data-final-fixes`).
- Подключение к существующему сохранению безопасно; `space_travel_required = true`.
- Опциональные зависимости (`? quality`, `? PlanetsLib`, `? space-exploration`) не требуются.

## Структура

- `prototypes/` — 14 файлов: группа, контролы автоплейса, предметы, жидкости, категории
  рецептов, ресурсы, тайлы, декорации, машины, рецепты, технологии, достижения, мапген, планета.
- `control.lua` — суперштормы, скриптовые достижения, награда за шпиль.
- `graphics/` — иконки, технологии, достижения, спрайтшиты руд, спрайты декораций.
- `tools/` — `gen_icons.py` (генерация графики), `check_lua.py` и `check_icons.py` (статические проверки).
- `docs/` — RESEARCH, DESIGN, ARCHITECTURE, GRAPHICS, TESTING, ROADMAP.

## Тестирование

Локальный запуск Factorio в этом окружении невозможен, поэтому применяются статические проверки:

```bash
python3 tools/check_lua.py     # синтаксис всех .lua (luaparser) + пути графики + локали + покрытие рецептов
python3 tools/check_icons.py   # целостность PNG: размер/режим/прозрачность/разнообразие
```

Перед публикацией также рекомендуется ручная проверка в игре (см. docs/TESTING.md).
